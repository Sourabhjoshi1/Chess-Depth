# Student joining kit

Six-page ChessDepth Academy Student Joining Kit (A4 PDF), personalised on the cover.
Copy `example.json`, change the details, then run `python3 joining_kit.py student.json`.

- Group students: set `batch` (e.g. `Beginner Circle Alpha 014A`); the cover shows "Format: Group: <batch>".
- One-to-one students: leave `batch` out; the cover shows "One-to-one".
- `class_time` is optional; leave it empty for the coach to fill in.
- Use the same scholar number as the admission letter (`../admission-letter`).
