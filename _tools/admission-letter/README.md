# Admission letter

One-page ChessDepth Academy letter of admission (A4 PDF).
Copy `example.json`, change the student details, then run `python3 admission.py student.json`.
Add the scholar number on /lab/admin/ as well, so it works in the Student Area and Chess Lab.

Group students: set `batch` to the batch name, e.g. `Beginner Circle Alpha 014A` (level + Circle + Greek letter + batch code). Leave it out for one-to-one students.
